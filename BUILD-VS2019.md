# Сборка PMLMRIM в Visual Studio 2019

## Требования

- Windows с Visual Studio 2019 и рабочей нагрузкой **Desktop development with C++**.
- Установленный компонент **C++ Windows XP Support for VS 2017 (v141) tools**, то есть `v141_xp`.
- Заголовки, библиотеки и общие файлы сборки подходящей версии Miranda NG **0.96.7 или 0.96.8**.

## Расположение проекта

Из выбранной папки `0.96.7/` или `0.96.8/` перенесите каталог `protocols/PMLMRIM/` в дерево исходников соответствующей Miranda NG, чтобы итоговый путь выглядел так:

```text
C:\Miranda0967\protocols\PMLMRIM\PMLMRIM.vcxproj
```

Для 0.96.8 путь аналогичен, но используйте её SDK. Если пути к `newpluginapi.h` или `mir_core` не находятся, проверьте дерево Miranda и свойства проекта.

## Параметры

1. Откройте `PMLMRIM.vcxproj` в VS 2019.
2. Выберите **Release | Win32**.
3. В **Project Properties → General → Platform Toolset** установите **v141_xp**.
4. Проверьте `C/C++ → Code Generation → Runtime Library`: Release-CRT, а не Debug (`/MD`, если это требуется сборкой Miranda).
5. Выполните **Clean**, затем **Rebuild**.
6. Убедитесь, что скомпилирована **DLL x86**; копируйте её в `Plugins` Miranda NG той же разрядности и версии.

Нельзя утверждать, что одна DLL совместима со всеми Windows/версиями Miranda только потому, что используется `v141_xp`. Для Windows XP может потребоваться соответствующая версия VC++ Runtime; не используйте DLL с зависимостями от отладочных `*D.dll`.

## Проверка после сборки

Проверьте загрузку в Miranda NG, подключение, прокрутку/группы контакт-листа, обычные и X-статусы, авторизацию, аватары. Файловую передачу проверяйте между двумя клиентами и учитывайте отсутствие MRIM-прокси.
