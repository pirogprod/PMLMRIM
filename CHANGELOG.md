# История изменений PMLMRIM

## 2026-11-05 — x86 DEP LIFECYCLE HARDENING (тестовая)

- Для Win32 в `0.96.7` и `0.96.8` изменён только `src/proto.cpp`: синхронизация доступа к списку протокольных аккаунтов во время callback обновления X-Status; проверка валидности окна диспетчера; исключение указателя на аккаунт перед его `Shutdown()`.
- x64 (`0.96.7`/`0.96.8`) сохранён без изменений.
- Исходный DEP-отчёт не содержит пригодного стека с символами, поэтому причина аварии не установлена. Это кандидат усиления защиты, а не гарантированное решение.
- Проверены состав архива и сопоставление файлов; компиляция в Visual Studio и тесты на XP/Windows не проводились.

## 2026-11-05 — подготовка исходников для GitHub (тестовая)

- Поиск: `WP_REQUEST`/`ANKETA_INFO`, ACK и тайм-аут (ранее `SearchBasic` имитировал найденного пользователя).
- Поиск по e-mail: добавлены `SearchByEmail` и объявление `PF1_SEARCHBYEMAIL` для вызова из интерфейса Miranda.
- Настройки: выбор `UTF-16LE` либо `Windows-1251` для **исходящих** сообщений; настройка отдельно для аккаунта.
- Исправлено `C2660` в Miranda NG 0.96.8 для обеих архитектур: `db_add_contact(m_szModuleName, 0)` в двух исходных файлах.
- Обновлён GitHub-комплект и русская документация. **Реальная сборка и интеграционное тестирование этой версии в Windows не проводились в среде подготовки архива.**

## Ранее

- x86: исправления контактов и отображения X-Status, проверки регистрации контактов, перенос обновления дополнительных иконок в GUI-поток, исправление C2248.
- XP x86: конфигурация Release, `v141_xp`, `/Od`, обычная CRT вместо Debug CRT.
- x64: сохранена отдельная линия исходников; новые изменения поиска/кодировки/0.96.8 присутствуют и в ней.

**Ограничения:** MRIM-сервер может не поддерживать поиск, а передача файлов остаётся экспериментальной. Не объявляйте эту ревизию проверенным стабильным релизом без тестов.
