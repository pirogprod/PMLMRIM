# Релиз: Unified XP-compatible VS2019

Одна ветка исходников под XP и новые Windows; отдельные деревья для Miranda 0.96.7 и 0.96.8. Использована последняя XP-сборка исходников с исправлением `WC_ERR_INVALID_CHARS`. Изменены только структура упаковки и документация. Проверку на Windows XP необходимо выполнить отдельно.
