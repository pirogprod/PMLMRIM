# PMLMRIM 0.96.8 — простое определение клиента для Tipper

* В MRIM USER_STATUS (версия 1.14+) после email читаются опциональные LPS features и LPS User-Agent.
* Непустое поле User-Agent записывается в базу контакта: модуль аккаунта PMLMRIM, настройка `MirVer` (Unicode).
* При офлайне или отсутствии User-Agent устаревшее значение `MirVer` очищается. Выдуманное название клиента не подставляется.
* Сеть, X-статусы, их иконки, список контактов и исходящая кодировка CP1251 не изменялись.

## Tipper

В «Настройки → Плагины → Tipper → Элементы» добавьте поле «Клиент» со значением:

    %raw:/MirVer%

Пустой `MirVer` не отображается. Учитывайте: определение возможно лишь если сервер прислал поле User-Agent. Старые варианты MRIM и некоторые серверы его не посылают.

## Проверка

Перенесённое чтение User-Agent проверено отдельно с помощью g++ на тестовых пакетах с LPS User-Agent и без него. MSVC/Miranda и реальный сервер в этом окружении не тестировались.
