PMLMRIM (Miranda NG 0.96.7) — тестовая доработка X-статусов

Основа: PMLMRIM-XStatus-PMLICQ-style-clear-fix.zip (рабочая очистка X-иконок сохранена).

1. Пункт основного меню статусов: X-status: <выбранный> (с обновлением при построении меню).
2. Галочка в контекстном списке выбора X-статусов.
3. URI / заголовок / текст сохраняются в базе аккаунта; LOGIN2 отправляет их при переподключении.
4. При смене обычного статуса X-статус пересылается заново, а не сбрасывается простым CHANGE_STATUS.
5. Окно установки текста уменьшено до 278x94 диалоговых единиц.
6. Заголовок/текст X-статуса кодируются UTF-16LE как MRIM Unicode strings; обычные сообщения не затронуты.
