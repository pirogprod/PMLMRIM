PMLMRIM — X-status icon fix (Miranda NG 0.96.7)

1. Восстановлен вызов ExtraIcon_SetIcon ТОЛЬКО после проверки: контакт не offline, XStatusActive=1, URI относится к поддерживаемым status_29..status_45, есть загруженная иконка.
2. Удалена загрузка резервной иконки ресурса 33004 из ExtraIcon. Нет подстановки иконки, если не найден X-статус.
3. При отсутствии X-статуса слот PMLMRIM очищается.
4. Сохранены текстовые X-статусы, Tipper, диалог и предыдущая замена 88.ico.

ВАЖНО: иконка @ справа на скриншоте, скорее всего, является НЕ X-статусом, а встроенным дополнительным значком «Протокол» Miranda NG, который показывается всем контактам. Если @ остаётся, открой Настройки -> Список контактов -> Дополнительные значки и выключи пункт «Протокол / Protocol». Это отдельный слот, PMLMRIM не может определять его видимость через XStatusActive.
