# MRIM передача файлов — промежуточная техническая часть

Дополнено `src/mrim_file_stream.h/.cpp`: разбор и построение списка файлов `filename;size;`, проверка имён, ограничение размера и количества, формирование/сопоставление P2P-команд `MRA_FT_HELLO` и `MRA_FT_GET_FILE`.

Тест: `g++ -std=c++14 src/mrim_file_stream.cpp tests/file_stream_test.cpp -o file_stream_test && ./file_stream_test` — прошёл.

**Файлы через Miranda NG в этой версии по-прежнему не передаются.** Нет интеграции с интерфейсом и службами Miranda (`SendFile`/`FileAllow`/`FileDeny`/`FileCancel`), сокетного P2P-транспорта, прокси MRIM, управления процессом, прогресса, отмены и проверки на двух клиентах. `PF1_FILE` специально не включён, чтобы не рекламировать неработающую функцию.

Существующие функции авторизации, статусов, анкет не изменялись.
