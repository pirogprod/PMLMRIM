# Обновление существующего репозитория GitHub

1. Сохраните резервную копию текущего репозитория или создайте отдельную ветку перед заменой исходников.
2. Распакуйте содержимое каталога **PMLMRIM/** этого архива в корень репозитория. Сохраняйте структуру и регистр имён.
3. В новой структуре `windows-xp-x86/` содержит исходники для 32-битных сборок, а `x64/` — для 64-битных. Старую папку `normal/` проверьте вручную и удаляйте только после сверки с `x64/`: автоматическое удаление может потерять пользовательские изменения.
4. Обновите описание репозитория и README, отметив статус тестирования поиска, кодировок и SDK 0.96.8.
5. Проверьте licensing/provenance notices — они перенесены из предыдущего GitHub-комплекта, **не подтверждают автоматически права на все изображения и код**.
6. Не добавляйте профили Miranda, пароли, токены, персональные логи, `Debug/`, `Release/`, `*.obj`, `*.pdb` и тестовые DLL в коммит.
7. После локальной сборки проверьте работу, затем коммит и тег/релиз. Не выдавайте исходный тестовый ZIP за проверенную готовую DLL.

## Обновление x86 DEP

Этот архив содержит дополнительно x86 DEP LIFECYCLE HARDENING. Не публикуйте его как проверенный стабильный релиз до проверки компиляции и работы на тестовом профиле. X64-файлы этого патча не затронуты. Сохраняйте PDB с точным соответствием DLL для диагностики.
