# PMLMRIM x86 — исправление-кандидат №2

Основа: предыдущий PMLMRIM GROUP FIX для Miranda NG 0.96.7 / 0.96.8.

**Изменения только для Win32:** на время проверки отключена регистрация и обновление X-Status extra icons, в том числе вызовы `ExtraIcon_SetIcon` из сетевого потока. Группы через `Clist_ContactChangeGroup`, список контактов и сообщения остаются включёнными.

Причина: CrashDumper показывает `mir_app.mir!Ordinal826`, чтение `0x0000009C`, но не позволяет однозначно связать сбой с группами или extra icons. Это диагностическое исправление, а не доказательство первопричины.

После сборки **Release | Win32** на копии профиля проверь подключение, контакты, группы и сообщения. Лог: `%TEMP%\PMLMRIM-x86-FIX-TRACE.txt` — строки `GROUP`, `ROSTER` и `XICON`. При вылете нужен этот лог и стек вызовов Visual Studio с загруженным PDB PMLMRIM. Не использовать Debug DLL для распространения.

**x64 не изменена** в плане поведения: дополнительные ветки компилируются только под `_M_IX86`. Для x86 X-Status extra icons временно недоступны.
