# PMLMRIM BETA 3 — исправление компиляции Avatar API (Miranda NG 0.96.8)

## Исправления

1. `src/stdafx.h`: добавлен `#include <m_avatars.h>`. Он объявляет `PS_GETAVATARCAPS`, `AF_*`, `PIP_SQUARE`, которые отсутствовали при компиляции `proto.cpp` и `avatar.cpp`.
2. `src/proto.cpp`: `GetCaps(PFLAGNUM_4)` теперь возвращает `PF4_AVATARS`, иначе AVS не инициирует загрузку аватаров.
3. Сетевая загрузка изображений, настройки avatar server/port, сообщения и X-статусы не изменялись.

Предупреждения C26495 в `m_gui.h` относятся к внешнему заголовку Miranda SDK и не связаны с указанными ошибками C2065.

Статическая проверка выполнена; полную компиляцию MSVC выполнить в этой среде нельзя.
