PMLMRIM: исправление лишних X-иконок по образцу PMLICQ

Суть: в ApplyXStatusIcon() заменена очистка ExtraIcon_Clear(handle, contact)
на ExtraIcon_SetIcon(handle, contact, INVALID_HANDLE_VALUE), как в рабочем
обработчике X-статусов PMLICQ.

При отсутствии подтвержденного X-статуса, офлайне или неподдерживаемом URI
значок в слоте должен быть именно отсутствующим. При подтвержденном URI
status_29...status_45 ставится соответствующее изображение.

Остальные файлы исходного архива сохранены. MSVC сборка не выполнялась.
