# File API: исходники, не рабочая передача

Добавлены переопределения Miranda NG `SendFile`, `FileAllow`, `FileDeny`, `FileCancel` с сигнатурами из m_protoint.h. Они безопасно возвращают ошибку и не создают ложный успех. `PF1_FILE` по-прежнему не объявляется.

**Файлы НЕ отправляются и НЕ принимаются**: отсутствуют обмен и привязка реальных сеансов, прямой TCP-слушатель/клиент, MRIM-прокси, входящее событие Miranda, сохранение файлов на диск и ACK прогресса. Нельзя считать этот архив исправлением «Невозможно начать передачу». DLL не собиралась.
