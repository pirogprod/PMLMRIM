# PMLMRIM — единые XP-совместимые исходники для Miranda NG

PMLMRIM — экспериментальный плагин протокола Агент@Mail.Ru (MRIM) для **Miranda NG 0.96.7 и 0.96.8**.

## Варианты

В этом репозитории поддерживается **одна XP-совместимая линия исходного кода** с двумя деревьями под разные версии Miranda NG:

| Папка | Целевая Miranda NG | Рекомендуемая сборка |
| --- | --- | --- |
| `0.96.7/` | 0.96.7 | Visual Studio 2019, `Release / Win32`, `v141_xp` |
| `0.96.8/` | 0.96.8 | Visual Studio 2019, `Release / Win32`, `v141_xp` |

Это **не одна общая DLL**: для разных версий Miranda NG сборка выполняется отдельно. Результаты сборки также должны совпадать с разрядностью установленной Miranda NG.

Исходники ориентированы на **Windows XP SP3 (x86)** и могут собираться для использования на более новых Windows; работоспособность каждого сочетания ОС, Miranda и зависимостей требует отдельной проверки. В архив не входят готовые DLL.

## Возможности

- Подключение к совместимому MRIM-серверу, сообщения, контакты и авторизация.
- Обычные и расширенные статусы, текст статуса, анкеты и аватары.
- Исправленные XP-совместимые иконки X-статусов и уменьшение лишних обновлений контакт-листа.
- Экспериментальная прямая TCP-передача файлов. **MRIM-прокси / обход NAT не реализован**; работу отправки и приёма нельзя считать подтверждённой.

## Сборка

Подробная инструкция — в [`BUILD-VS2019.md`](BUILD-VS2019.md). Требуются соответствующие исходники/SDK Miranda NG.

## Статус проверки

Код сформирован на базе последнего XP-патча `PMLMRIM-XP-x86-0967-0968-WC-C2065-FIX.zip`. Архив и ресурсы проверены, но **фактическая Windows-сборка, загрузка DLL и работа на XP не проверены**.
