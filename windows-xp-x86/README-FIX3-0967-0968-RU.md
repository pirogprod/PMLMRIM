# PMLMRIM x86 FIX3 — восстановление загрузки контактов и диагностика сообщений

Основано на FIX2, отдельно для Miranda NG 0.96.7 и 0.96.8.

- На x86 временно отключены вызовы API групп **из сетевого потока** (Clist_GroupExists / Clist_GroupCreate / Clist_GetGroup / Clist_ContactChangeGroup). Существующие локальные назначения групп в базе сохраняются; восстановление серверных групп требует отдельного безопасного этапа.
- На x64 старый групповой код сохраняется.
- Создание, импорт контактов, статусы и приём сообщений не отключены.
- Создаётся журнал `%TEMP%\PMLMRIM-x86-FIX-TRACE.txt`, содержащий типы пакетов (числа), число записей и результата занесения в БД. Имена, адреса и тексты сообщений не записываются.
- Для анализа также нужен `%TEMP%\PMLMRIM-roster.txt`.

**Как проверить:** перед запуском закройте Miranda, сохраните копию профиля и удалите старые диагностические журналы. Соберите `Release | Win32`, включите один MRIM-аккаунт, подключитесь, отправьте входящее сообщение с другого клиента, затем пришлите оба журнала. Отдельно проверяйте x86 на 0.96.7 и 0.96.8.

**Статус:** диагностическая сборка-кандидат; компиляция и работоспособность не подтверждены. Группы намеренно не синхронизируются в x86, пока не локализован исходный сбой; это не финальный полноценный фикс.
