# MRIM файловый транспорт: TCP-слой (НЕ ГОТОВАЯ ПЕРЕДАЧА)

Добавлены mrim_file_connection.h/.cpp: разбор IP:PORT из MRIM, TCP connect с timeout, TCP listener на случайном порту и I/O timeout; код включён в Visual Studio проект с Ws2_32.lib.

Это низкоуровневые функции, но они ещё не вызываются из SendFile/FileAllow, и Miranda NG не получает события входящих предложений или прогресса. MRIM proxy 0x1044–0x1047 не реализован.

НЕ устанавливайте эту версию вместо рабочего плагина с ожиданием поддержки передачи файлов. Нельзя заявлять PF1_FILE до завершения интеграции. Сборка Windows не проверена.
