# PMLMRIM 0.96.7 — исправление кодировки исходящих текстовых X-статусов

Исправлено несоответствие: входящие название и описание X-статуса декодируются из CP1251, а предыдущая версия отправляла UTF-16LE, **не согласовав UTF16CAPABLE**. В результате другие клиенты могли показывать квадраты и битый текст.

Изменено:
- `src/proto.cpp`: `SetExtendedStatus` отправляет название и описание в CP1251 при `CHANGE_STATUS`.
- `src/server.cpp`: `LOGIN2` отправляет название и описание в CP1251 при первоначальном подключении / переподключении.
- Уточнены комментарии кодека. Остальное, включая работающее скрытие X-иконок у контактов без статуса, сохранено.

**Проверка:** после сборки на PMLMRIM выбрать X-статус, написать `Привет! Всё отлично`, убедиться, что на другом клиенте виден русский текст; затем отключить/подключить аккаунт и повторить. Если сервер требует Unicode-режим, потребуется отдельное согласование возможности UTF16CAPABLE — просто слать UTF-16LE без неё нельзя.

Архив прошёл статические проверки; сборка MSVC и обмен с реальным сервером не выполнялись.
