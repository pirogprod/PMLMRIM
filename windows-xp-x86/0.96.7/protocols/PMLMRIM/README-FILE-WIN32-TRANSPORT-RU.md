# Файловый TCP-адаптер Win32 — незавершённая интеграция

Добавлены `mrim_file_win32.h/.cpp` и включение нового CPP в vcxproj.
Адаптер связывает существующие `serveFileRequests` / `requestFiles` с Winsock `send/recv` и Win32 `ReadFile/WriteFile`.
Входящий файл создаётся только через `CREATE_NEW`, опасные имена отклоняются; при сбое незавершённые новые файлы удаляются.
Источники проверяются по размеру до отправки.

**ВАЖНО:** интеграция не завершена. Этот адаптер вызывается только при наличии уже согласованного и установленного `SOCKET`. Вызова из `SendFile` / `FileAllow` пока нет, соединения/прокси нет, события прогресса Miranda не подключены. `PF1_FILE` оставлен выключенным. Данная сборка не исправляет невозможность запуска передачи файлов в Miranda NG.

Для Windows-валидирования необходимы сборка в исходном дереве Miranda NG и реальный тест двумя клиентами.
