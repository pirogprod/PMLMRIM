## Реализованное и ограничения

### Сообщения, контакты, авторизация

В коде и сопроводительных README описаны взаимодействие с сервером, создание контактов, текстовые сообщения и обработка флага запроса авторизации MRIM `0x08` через механизм Miranda NG. Функциональность требует проверки с конкретной версией сервера.

### Статусы, анкеты, аватары

Представлены X-статусы, текстовые статусы, визуальные ресурсы и обработка анкет. Для аватаров реализовано HTTP-получение с отдельного сервера и кэширование; обновление **своего** аватара не заявлено как готовая функция. Доступность старых адресов серверов не гарантируется.

### Передача файлов

В `mrim_file_api.cpp` имеется интеграция с `SendFile`, `FileAllow`, `FileDeny`, `FileCancel`; кодом предусмотрены согласование MRIM, прямой TCP-транспорт, Win32-файловый ввод-вывод и уведомления `ACKTYPE_FILE`.

**Критические ограничения:**

- Не реализован MRIM-прокси для обхода NAT.
- Не реализован резервный путь соединения при неудаче исходного подключения.
- Нет подтверждённого сквозного теста между двумя работающими экземплярами Miranda NG в Windows.
- Поддержка нестандартных серверов, отмены на всех этапах и кириллицы в именах файлов требует практической проверки.

Заявлять «полностью рабочую передачу файлов» без этих тестов нельзя.

## Сборка и переносимость

Файл `PMLMRIM.vcxproj` импортирует `..\..\build\vc.common\plugin.props`. Это означает зависимость от структуры полного дерева Miranda NG; одних исходников плагина недостаточно для самостоятельной сборки. Понадобятся корректные пути к SDK, Windows SDK, MSVC и выбранной версии клиента. Нативная сборка и интеграционное тестирование в рамках этого аудита не выполнялись.
