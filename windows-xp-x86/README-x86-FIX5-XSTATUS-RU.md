# PMLMRIM x86 FIX5 — восстановление значков X-Status

База: FIX4 (рабочая у пользователя загрузка контактов), изменения только в `proto.cpp`.

## Что изменилось
- Убрано предыдущее отключение `ExtraIcon_RegisterCallback` для x86.
- Возвращены загрузка ресурсов и назначение значков X-Status.
- Сетевые потоки **не вызывают** `ExtraIcon_SetIcon` напрямую: обновления передаются в оконный поток посредством `PostMessageW` в message-only окно, созданное в OnModulesLoaded.
- При освобождении последнего MRIM-аккаунта окно закрывается синхронно, чтобы уменьшить риск обращения к выгруженному коду.
- Проверки состояния контакта (`Offline`, `XStatusActive`, допустимый URI, наличие ресурса) сохранены.
- x64 оставлена с прежним режимом непосредственного обновления значков.

## Проверка
1. Сохранить предыдущую DLL FIX4, профиль и настройки.
2. Собрать Release|Win32 для 0.96.7 либо 0.96.8 и заменить DLL только в **тестовой x86 Miranda**.
3. Убедиться, что список контактов и сообщения сохранились; проверить X-Status на контакте, который фактически передаёт поддерживаемый `status_N`.
4. Проверить переключение Online/Offline, повторные подключения и закрытие Miranda.
5. При вылете приложить CrashDumper, стек Visual Studio и `%TEMP%\PMLMRIM-x86-FIX-TRACE.txt`.

**Статус:** кандидат, компиляция и запуск в Miranda здесь не проводились.
Отдельные значки появятся только при наличии поддерживаемого серверного X-Status и включённой колонке extra icons в контакт-листе.
