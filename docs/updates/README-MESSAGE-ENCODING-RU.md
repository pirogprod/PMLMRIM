# PMLMRIM — выбор кодировки сообщений в настройках аккаунта

Добавлена настройка **Message encoding** в оба окна PMLMRIM:
- Менеджер учётных записей — создание и редактирование аккаунта.
- Настройки PMLMRIM -> Network.

Варианты:
- **UTF-16LE (recommended)** — по умолчанию, MRIM MESSAGE с флагом Unicode 0x00100000. Подходит для клиентов, поддерживающих Unicode; позволяет отправлять символы за пределами Windows-1251.
- **Windows-1251 (legacy)** — отправка MRIM MESSAGE в старой однобайтовой кодировке без флага Unicode. Для старых клиентов. Символы, не представимые в 1251, **не подменяются на ?** — отправка такого текста завершится ошибкой кодирования.

Настройка сохраняется отдельно для каждой учётной записи в БД Miranda под ключом `MessageEncoding`: `1` — UTF-16LE, `0` — Windows-1251. Смена применяется к новым исходящим сообщениям после сохранения параметров. Новое подключение обычно не требуется.

**Входящие сообщения** по-прежнему определяются автоматически по MRIM-флагу Unicode; текст входящих без флага декодируется как Windows-1251. Кодировка логина, адресов контактов, серверного ростера, X-Status и поиска НЕ менялась.

Включены четыре варианта исходников: x86 XP Release и x64 (по два проекта — 0.96.7/0.96.8). Пакет основан на PMLMRIM SEARCH EMAIL FIX2, все существующие исправления сохранены.

## Проверка
1. Собрать нужный проект в VS 2019. x86: Release | Win32 / v141_xp. x64: штатная конфигурация.
2. Проверить, что оба пункта появляются в настройках, смена сохраняется после закрытия и повторного открытия окна.
3. Проверить отправку и получение кириллицы в обоих режимах, а также Unicode (например, эмодзи) только в UTF-16LE.
4. Проверить контакты, группы, X-Status и поиск после изменения настройки.
5. Проверить создание новой учётной записи и повторное подключение.

**Внимание:** это исходники для тестирования. Сборка и работа на реальных компьютерах, особенно на Windows XP, здесь не проверялись. Сохраните предыдущую DLL и резервную копию профиля.
