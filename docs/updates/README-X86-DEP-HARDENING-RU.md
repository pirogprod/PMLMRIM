# PMLMRIM — x86: защита жизненного цикла X-Status (тестовая сборка)

Основа: исходники PMLMRIM с поиском по e-mail, выбором кодировки и исправлением API `db_add_contact` для Miranda NG 0.96.8.

## Изменения (только x86)

- В `proto.cpp` синхронизирован доступ к общему списку экземпляров `CMrimProto` при регистрации, callback обновления X-Status и удалении аккаунта. Это устраняет конкретное потенциальное обращение к уничтоженному объекту при одновременном закрытии аккаунта и обновлении иконки.
- Перед вызовами UI-процедур проверяется, существует ли окно диспетчера X-Status и принадлежит ли оно живому GUI-потоку; сетевой поток больше не пытается обновить дополнительные иконки напрямую при отсутствии окна.
- Экземпляр аккаунта убирается из списка callback **до** `Shutdown()`, чтобы новые UI-callback не использовали указатель на уничтожаемый аккаунт.
- Все изменения обёрнуты в `_M_IX86`. Исходники x64 сохранены без изменений.

## Ограничения и статус

**Это проверочный патч, а не доказанный фикс причины DEP-краша.** Crash Report от 2026-11-05 20:02:43 показывает DEP на неизвестном адресе, но не содержит кадров PMLMRIM. В процессе также работают PMLICQ и сторонняя инъекция Windhawk. По одному отчёту нельзя установить виновный модуль.

Не проверено: компиляция в Visual Studio, стабильность на Windows XP и фактическая причина указанного DEP-вылета.

## Сборка и проверка

1. Создать резервную копию `profile.dat`, текущей `PMLMRIM.dll` и `PMLICQ.dll`.
2. Visual Studio 2019: выбрать нужную версию 0.96.7/0.96.8, `Release | Win32`, toolset `v141_xp`, PDB (`/Zi` и `/DEBUG`).
3. Установить DLL только в тестовую копию portable Miranda.
4. Проверить: первый запуск, создание нового MRIM-аккаунта, отключение/повторное подключение, удаление/создание аккаунта, поиск по e-mail, сообщения, X-Status, выход из Miranda.
5. Если DEP повторится — приложить стек Visual Studio (Ctrl+Alt+C), DLL+PDB одной сборки. Для изоляции повторить тест отдельно с выключенным PMLICQ и отдельно без Windhawk.

**Не публиковать как стабильную версию до успешной проверки.**
