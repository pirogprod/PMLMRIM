# PMLMRIM — исправление C2660 для Miranda NG 0.96.8

Исправлены две ошибки C2660 «db_add_contact: функция не принимает 0 аргументов» в `src/proto.cpp` и `src/server.cpp` для x86 и x64.

В исходниках 0.96.8 теперь используется только `db_add_contact(m_szModuleName, 0)`; старая ветка `db_add_contact()` удалена из 0.96.8. Для этих вызовов не требуется отдельный `Proto_AddToContact`, так как имя протокола задаётся при создании контакта.

**0.96.7 не изменена.** Функции выбора кодировки, поиска, X-Status, работы с сообщениями и другими контактами не менялись.

Сборка: Visual Studio 2019, версия 0.96.8, нужная архитектура x86 или x64. Перед сборкой выполнить «Пересобрать решение», убедившись, что пути include соответствуют SDK 0.96.8.

Патч проверен как изменение исходников и целостность архива. Компиляция в Visual Studio и запуск под Windows здесь не проводились.
