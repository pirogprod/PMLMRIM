# PMLMRIM — SEARCH EMAIL FIX2 (тестовый патч)

## Причина ошибки

В окне «Найти/Добавить контакт» Miranda NG радиокнопка «Адрес e-mail» вызывает сервис `PS_SEARCHBYEMAIL`, связанный с виртуальным методом `PROTO_INTERFACE::SearchByEmail(const wchar_t *)`. В предыдущем SEARCH FIX мы реализовали только `SearchBasic()` (сервис `PS_BASICSEARCH`), поэтому поиск по e-mail не попадал в обработчик и Miranda показывала «Не могу запустить поиск...». Проверено по исходникам Miranda NG.

## Исправления

* Добавлен `SearchByEmail(const wchar_t *) override` для версий 0.96.7 и 0.96.8, x86 и x64.
* Добавлен `PF1_SEARCHBYEMAIL` в `GetCaps(PFLAGNUM_1)`.
* Новый метод направляет e-mail в **тот же** `SearchBasic()`, где уже находятся проверка корректности e-mail, отправка `WP_REQUEST`, ожидание `ANKETA_INFO`, тайм-аут и ACK.
* Работа контактов, сообщений, групп, X-Status и настройки Win32 XP Release не изменялись.

## Тестирование

1. Сделать резервную копию рабочей DLL и профиля.
2. Скомпилировать соответствующий проект Miranda NG 0.96.7 либо 0.96.8 для нужной архитектуры.
3. Перезапустить Miranda, убедиться, что PMLMRIM находится в Online.
4. «Поиск контактов» → выбрать PMLMRIM → «Адрес e-mail» → ввести **полный** адрес → начать поиск.
5. Если появляется окно «Не могу запустить поиск», убедиться, что именно новая DLL реально загружена: проверить дату, путь и PDB, затем трассировать вызов `SearchByEmail()`.
6. Если поиск запускается, но результата нет, изучить Netlib Log со строками `MRIM SEARCH: WP_REQUEST sent` и `MRIM SEARCH: ANKETA_INFO ...`.

**Ограничение:** код не собран/не испытан на настоящем MRIM-сервере в данной среде. Реальная работа сетевого поиска зависит от поведения сервера и требует проверки. Это тестовая версия, а не подтверждённый стабильный релиз.
